# Rail

Стеклянный сайдбар слева для macOS: все открытые окна всех приложений вертикальным списком, как вкладки в Arc, сгруппированные по проектам.

## Суть
- Выезжает при наведении на левый край экрана (или по хоткею)
- Окна сгруппированы по проектам: «Проект A» → VS Code, Figma, 2 вкладки Chrome
- Окна можно закреплять, переименовывать, перетаскивать между группами
- Клик по группе разворачивает её окна и прячет остальные
- Стекло macOS 26 как у переключателя ⌘Tab: `NSGlassEffectView` с приватным вариантом 23 (`GlassBackground.swift`); SwiftUI `.glassEffect()` на большой панели выходит тёмным и мутным

## Отличие от челки
Челка: быстрые действия (буфер, AirDrop). Rail: долгоживущая навигация по окнам и проектам.

## Тех. заметки
- `NSPanel` non-activating, поверх всех окон
- Список окон: Accessibility API (`AXUIElement`) + `CGWindowListCopyWindowInfo`; окна с других Spaces через приватные `_AXUIElementCreateWithRemoteToken` / `_SLPSSetFrontProcessWithOptions` (как в AltTab), см. `PrivateAPI.swift`
- Нужно одно разрешение, Accessibility: заголовки окон и вкладок приходят из AX, а номера окон и владельцы из `CGWindowListCopyWindowInfo` не требуют Screen Recording

## Статус
- [x] v0.1: панель у левого края, список окон по приложениям, клик выводит окно вперёд
- [x] Проекты: правила «приложение + слово в заголовке», хранятся в UserDefaults; правый клик по окну → «Добавить в проект»
- [x] Окна со всех рабочих столов (Spaces): AX видит только текущий, остальные находятся перебором `_AXUIElementCreateWithRemoteToken`, переключение через SkyLight; приложения без окон внизу иконками
- [x] Вкладки браузеров (Chrome и родня, Safari, Firefox) отдельными строками из полосы вкладок в AX; правила проектов работают и по вкладкам
- [x] Браузер — любое приложение, открывающее https-ссылки (Tor, форки Firefox и т.п. без списка); Firefox строит AX-дерево только после `AXEnhancedUserInterface`. Системные вкладки macOS (Finder, Terminal) тоже строками; их скрытые окна отсеиваются по `SLSCopySpacesForWindows`
- [x] Закреплённые пункты проекта: правый клик → «Закрепить». Пин помнит приложение, заголовок и адрес (URL вкладки из `AXDocument` окна или веб-области, файл документа из `AXDocument`; Finder документа не сообщает, его папка вычисляется по путям файлов в окне, `Finder.swift`); закрытый пин остаётся бледной строкой и по клику открывает адрес в том же приложении. Адрес фоновой вкладки читается, на миг выбрав её. Приложения без вкладок и документов (Telegram и прочие чаты) не сообщают, что открыто в окне: такой пин просит название и ссылку (для Telegram `@username`, номер, `t.me/…` → `tg://resolve`), и клик открывает ссылку, даже когда окно приложения открыто. Slack (`Slack.swift`): канал из адреса страницы `app.slack.com/client/T…/C…` (дерево Electron включается `AXManualAccessibility`), открытый тред из ссылки на первое сообщение в панели треда; Slack открывает только `slack://channel?team=…&id=…&message=…&thread_ts=…`, ссылки «Copy link» переводятся в него
